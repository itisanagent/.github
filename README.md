### What is "It Is An Agent."?

*"It Is An Agent." is a local AI-agent tool that help you code, fix your printers, send emails, and other stuff.*

### Is it public?

*No, the tool is in early development stage, and its far from perfect. But, you may see it in projects of [dnd-ed](https://github.com/dnd-ed) or [itzdanti](https://github.com/itzdanti) because we are constantly updating and testing it.*

### What features does it have?

*As I said, the tool is in early development stage, and its far from perfect, so we can't tell what exactly will be in it, but you can expect:
- MCP Server Support
- Planning
- Tool calling
- Agent Looping
- Reasoning
- Scaffolding
- Memory
- Multi-Agent System
And much, MUCH more...*
